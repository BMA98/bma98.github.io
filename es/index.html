Movie History

Aplicación web diseñada para llevar un registro histórico de las películas vistas.

Un servicio backend desarrollado con Django REST Framework actúa como driver de la base de datos PostgreSQL para mantener las entidades de películas, las personas que trabajan en ellas, los usuarios y el historial mismo. Expone varios endpoints para entregar funcionalidades de listado, detalle y creación de objetos.

Un servicio frontend desarrollado con VueJS y Vuetify que consume el servicio backend, permitiendo al usuario ver su historial, los detalles de las películas vistas, los detalles de las personas involucradas e interacciones básicas como puntuar películas y agregar nuevas entradas al historial.

Los datos que alimentan la base de datos provienen de The Movie Database.
